Bem-vindo ao Amigo Despachante 🚗

Este tutorial cobre 100% do sistema — do primeiro acesso à geração de relatórios. Leia uma vez e tenha o sistema no sangue!

1. Primeira OS 2. Clientes 3. Pagamento 4. Impressão 5. Kanban 6. Financeiro 7. WhatsApp 8. IA / Chat 9. Relatórios 10. Backup
1
Criando sua primeira Ordem de Serviço (O.S.)
O coração do sistema — tudo começa aqui
  1. No menu lateral, clique em ➕ Nova O.S.
  2. Preencher com Print (OCR): se você tem um print da notificação DETRAN ou do sistema do cliente, clique em "📸 Preencher com Print". O sistema usa IA para extrair automaticamente placa, RENAVAM, nome do cliente e mais. Economiza 2 minutos por OS.
  3. Buscar cliente existente: se o cliente já está cadastrado, use o campo de busca por CPF ou nome. Os dados são preenchidos automaticamente.
  4. Selecione o Tipo de Serviço (licenciamento, transferência, etc.). O campo de Honorários é preenchido automaticamente com base na sua Tabela de Preços.
  5. Informe o valor Pago caso o cliente já pagou na hora. Se não pagou, deixe em 0.
  6. Clique em 💾 Criar O.S. — o sistema abre automaticamente o protocolo para impressão (3 vias).
💡 Use Ctrl + K em qualquer tela para abrir a busca global — encontre clientes, placas e OS em segundos.
2
Gerenciando Clientes
Histórico completo por CPF/CNPJ
  1. Acesse 👥 Clientes no menu. Veja todos os clientes cadastrados com nome, CPF e última OS.
  2. Clique no nome do cliente para ver o perfil completo: todas as OS, veículos, total pago e pendências.
  3. Importação em massa: se você tem uma planilha do sistema antigo, clique em "📥 Importar CSV". O sistema aceita Nome, CPF, Telefone, E-mail, Endereço.
  4. Cada cliente tem um botão direto de WhatsApp para contato rápido.
💡 Ao criar uma OS, o sistema detecta automaticamente se o CPF já está cadastrado e preenche todos os dados do cliente — nunca precisa digitar duas vezes.
3
Pagamento e Parcelamento
Controle financeiro por OS
  1. Dentro de uma OS, vá até o bloco 💳 Pagamento (coluna direita).
  2. Clique em ⚙️ Configurar e escolha o número de parcelas (1x, 2x, 3x… até 12x).
  3. Defina o vencimento da 1ª parcela — as demais são geradas automaticamente (mensal).
  4. Quando o cliente pagar, clique em ✓ Dar Baixa na parcela correspondente. Informe a forma de pagamento (PIX, Dinheiro, Cartão…).
  5. O sistema abre automaticamente o 🧾 Recibo para impressão ao dar baixa.
  6. Para estornar um pagamento errado, clique no botão ↩ ao lado do recibo.
⚠️ O campo Pago na criação da OS é para pagamento imediato à vista. Para parcelamento, configure depois pelo botão "⚙️ Configurar".
4
Impressão de Documentos
Protocolo, Procuração e Requerimento em um clique

Dentro de qualquer OS, no bloco 🖨️ Documentos para Impressão:

📋
Protocolo (3 vias)
Via do Despachante · Via do Cliente · Via do DETRAN. Impressão automática ao criar a OS.
📝
Procuração Particular
2 vias assinadas pelo cliente autorizando o despachante a representá-lo.
📄
Requerimento DETRAN
Formulário oficial pré-preenchido. Pode personalizar o texto na edição da OS.
🧾
Recibo de Pagamento
Gerado automaticamente ao dar baixa em uma parcela.
🖨️ Todos os documentos abrem em nova aba prontos para imprimir. Use Ctrl + P ou clique no botão de impressão. Guarde a via do DETRAN por 5 anos.
5
Kanban — Visão Geral das OS
Arraste e solte para mudar status
  1. Acesse 🗂️ Kanban no menu. Veja todas as OS organizadas por coluna: Abertas → Em Andamento → Concluídas → Canceladas.
  2. Arraste um card de uma coluna para outra para mudar o status diretamente — sem abrir a OS.
  3. Cada card mostra: placa, cliente, tipo de serviço e situação financeira (quitado ou pendente com valor).
  4. Use o Kanban como painel de operação diária — o que está para fazer hoje está em "Abertas".
💡 O número vermelho no dashboard indica OS paradas há mais de 7 dias + parcelas vencidas. Confira diariamente!
6
Financeiro
Faturamento, recebíveis e gráficos
  1. Acesse 💰 Financeiro no menu para uma visão geral do escritório.
  2. Faturamento por mês: gráfico de barras dos últimos 12 meses.
  3. Por tipo de serviço: quais serviços mais faturam no escritório.
  4. Por forma de pagamento: quanto entrou de PIX, dinheiro, cartão etc.
  5. OS pendentes: lista de ordens com saldo em aberto — para cobrar.
  6. Parcelas vencidas: parcelas que passaram do vencimento sem pagamento.
7
WhatsApp e Portal do Cliente
Comunicação profissional com um clique
  1. Dentro de qualquer OS com telefone cadastrado, o bloco 💬 WhatsApp aparece na coluna direita.
  2. Clique em ✅ OS Pronta para abrir o WhatsApp Web já com a mensagem preenchida avisando o cliente.
  3. Mensagens disponíveis: OS Pronta · OS Aberta · Aguardando Documentos · Cobrança.
  4. Edite os templates em 💬 Templates WhatsApp no menu — personalize com o nome do escritório.
  5. Portal do Cliente: clique em "🔗 Gerar link do cliente" para criar um link exclusivo que o cliente acessa pelo celular e vê o status da OS, documentos pendentes e saldo — sem precisar de login.
  6. Envie o link pelo WhatsApp com um clique.
8
IA Amigo — Assistente Virtual
Tire dúvidas do DETRAN-SC com IA
  1. Acesse 🤖 IA Amigo no menu.
  2. Faça perguntas sobre documentos necessários, prazos, procedimentos do DETRAN-SC, CNH, transferência, inventário etc.
  3. A IA usa uma base de conhecimento específica para despachantes de SC — respostas focadas no seu dia a dia.
  4. Alimente a 📚 Base de Conhecimento com circulares, portarias e resoluções do DETRAN-SC para que a IA fique cada vez mais precisa.
⚠️ A IA é um assistente de consulta — sempre verifique informações críticas no site do DETRAN-SC antes de orientar o cliente.
9
Relatórios
Produção, retenção e finais de placa
📊
Relatório de Produção
OS criadas por período, por tipo de serviço e por status. Exporta CSV para Excel.
🔄
Retenção de Clientes
Clientes que voltaram vs clientes que usaram apenas uma vez — mede a fidelização.
✅
Fez / Não Fez
Veículos que licenciaram com você vs os que não renovaram — identifique quem chamar de volta.
📋
Finais de Placa
Veja quantos clientes vencem em cada mês por final de placa — planejamento de demanda.
10
Backup e Segurança
Nunca perca seus dados
  1. Acesse 💾 Backup no rodapé do menu lateral.
  2. Clique para baixar um arquivo ZIP com todo o banco de dados do sistema.
  3. Guarde o backup no computador, pen drive ou Google Drive.
  4. Frequência recomendada: semanal ou após criar muitas OS.
  5. O banco de dados fica salvo no servidor Railway com volume persistente — os dados não são apagados em deploys ou reinicializações.
🔒 A senha geral de acesso ao sistema (DESP_PASSWORD) é configurada no painel do Railway. A senha de admin (para a Tabela de Preços) é configurada via DESP_ADMIN_PASSWORD.
