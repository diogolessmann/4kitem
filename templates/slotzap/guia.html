⚙️ O que o SlotZap faz por você (no automático)

  • ✓ Cria a página pública dos seus números (1 a 1000)
  • ✓ Gera o PIX automático quando o cliente escolhe um número
  • ✓ Marca o número como vendido sozinho quando o pagamento cai
  • ✓ Libera o número de volta se a pessoa não pagar em ~30 min
  • ✓ Deixa o cliente comprar vários números num PIX só
  • ✓ Sorteia o ganhador entre os pagos com 1 clique
  • ✓ Exporta a lista de compradores em planilha
  • ✓ Avisa no grupo do WhatsApp a cada venda (precisa de número conectado via MandaZap)

🏦 Como receber o dinheiro (cadastrar sua carteira Asaas)

Esse passo é obrigatório pra você receber automático. Sem a carteira, o dinheiro das vendas não chega até você. Leva 1 minuto:
  • 1. Crie uma conta gratuita no Asaas em asaas.com (se ainda não tem).
  • 2. No painel do Asaas, vá em Minha Conta → Integrações (ou Perfil → Dados da conta).
  • 3. Copie o seu Wallet ID — é um código tipo 8a7b6c5d-1234-...
  • 4. Cole em ⚙️ Config aqui no SlotZap e salve.
  • ✓ Pronto! A partir daí cada PIX pago manda {{ 100 - taxa }}% direto pra sua conta, na hora.
